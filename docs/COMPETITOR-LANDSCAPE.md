## 2. Patterns that win
- **Retention:** short sessions plus a visible path or map (Duolingo, Mathseeds, Khan Kids). Streaks work, but leaderboards are removed for children (Duolingo child accounts).
- **Motivation without loot boxes:** rewards that are *caused by learning*, such as a pet hatched per lesson (Mathseeds) or Khanmigo hats bought with points earned from practice. What fails is rewards that can be bought (Prodigy) or scores that punish a mistake (IXL).
- **Parent reporting:** a weekly log, flagged weak areas, monthly report cards, CSV/PDF export (Epic, SplashLearn, Prodigy). Khanmigo adds a chat transcript for parents.
- **Offline:** done well only by nonprofit or FOSS projects (GCompris, Kolibri, Kitkit, PhET, ScratchJr, Duolingo ABC). Every big commercial app requires an account.

## 3. Gaps nobody fills, which fit this app
1. **A Socratic tutor that runs entirely on the device, with no account.** Khanmigo is cloud, paid, 18+ signup; Socratic is gone. [Inferred from the table.]
2. **Wrong answers acted out in a story.** DragonBox hides the math, and Beast Academy uses comics on paper, but no app animates the *consequence* of the child's own answer. [Inferred]
3. **A modern, delightful FOSS app.** The FOSS options (GCompris, Kitkit, Sugar) are offline but look dated or are unmaintained. [Inferred]
4. **One permissive licence (MIT/Apache) for both code and content.** GCompris is AGPL, PhET and OpenStax are NC, and ScratchJr's EULA bans derivatives.
5. **Parent reporting that never leaves the device.** Every parent dashboard above lives in the cloud.

## 4. Ten ideas to steal or adapt
1. **A mascot per subject** (Khan Kids): Pip for math, new mascots for English and science, all in one world.
2. **Hints before, explanation after** (Khanmigo): keep the no-answer ladder until the child submits, then let Pip walk the error step by step. This answers Khan's own "needed more nuance" lesson.
3. **Ground any model in the worked solution and the child's error log** (Khanmigo): if an LLM is added later, pass it the script, the solution and the event log so it can't drift.
4. **Suggested-question chips** (Khanmigo): "Why fewer?", "Show me", "Give me a smaller one". Pre-readers can ask without typing.
5. **Picture first, notation later** (DragonBox): stickers become numerals, then equations. Then *close the transfer gap* DragonBox has by always ending with the written equation.
6. **The chest hatches something tied to the lesson** (Mathseeds pet per lesson): the chest drops a story item or a new mascot friend from the problem just solved. Never random, never for sale.
7. **One shared streak and XP across subjects** (Duolingo): build it into the shared core now, so English and science plug in later. Make it a gentle streak with "rest days" and no leaderboards.
8. **Manipulatives built for each concept** (Duolingo's clock): linked tools where moving one part moves the other, e.g. a number line linked to the sticker counters.
9. **Exportable parent log** (Epic CSV/PDF, Prodigy monthly report card): generate a weekly report on the device from the event log, which the parent can export or AirDrop. No server.
10. **Device-to-device sync and content packs** (Kolibri Morango, Kitkit offline bundle, ScratchJr export): sync two family iPads over the local network or by file, and ship curriculum as downloadable packs that teachers can fork.

Bonus: a **"Read To Me" toggle** in English and Spanish (Khan Kids) using the device's own speech; **free-play "Create" mode with no failure** (Toca Boca, Khan Kids "Create").

## 5. Five things to avoid
1. **Rewards you can buy, or a visible split between haves and have-nots** (Prodigy FTC complaint).
2. **Scores that drop after a mistake** (IXL SmartScore). Mastery should only ever go up within a session, and fade gently over time.
3. **Wrapping math in a game that doesn't teach** (Prodigy's "lack of remediation"; DragonBox's weak transfer). The story must *be* the explanation.
4. **Time-gated or ad-supported free tiers** (Epic school hours, SplashLearn ads), and billing traps (SplashLearn reviews).
5. **Drifting into an answer engine** (Socratic → Lens Homework). Never show the final answer first, even when an AI is added.
